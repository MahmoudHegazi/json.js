A JavaScript + HTML UI framework for single-page applications (SPA) with state management, full object-oriented programming support, and native type validation—no need for TypeScript. It allows importing and exporting state, and uses JSON to define HTML, app structure, and all components.

Designed for SPAs using only JSON-serializable objects (no non-primitive values), you can provide your own classes to handle logic while benefiting from smooth SPA features—such as rendering components without writing your own HTML or worrying about the view layer.

Just extend your component from the base Component class, define your JSON-based UI, create a new App(), and you're ready to go. You can even reduce or omit views, or dynamically modify the SPA UI for multi-page scenarios.
